# 🍔 Quick Bite Fast Food Website

## Project Overview

Quick Bite Fast Food is a responsive restaurant website designed to showcase delicious meals, provide information about the restaurant, display the menu, and allow customers to contact the restaurant.

## Objectives

- Create an attractive restaurant website.
- Display food items and their prices.
- Introduce the restaurant and its services.
- Provide a contact form for customers.
- Make the website responsive on desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server
- Unsplash for food images
