🍔 Quick Bite Fast Food Website

📌 Project Overview

Quick Bite Fast Food is a responsive restaurant website designed to showcase delicious meals, introduce the restaurant, display its menu, highlight its services, and allow customers to contact the restaurant.

The website provides a simple, attractive, and user-friendly interface that works on desktop computers, tablets, and mobile phones.

🎯 Project Objectives

* Create an attractive restaurant website.
* Display the restaurant’s food menu.
* Introduce the restaurant and its services.
* Provide contact information and a contact form.
* Make the website responsive across different screen sizes.
* Improve the online presence of the restaurant.

🛠️ Technologies Used

* HTML5: Structures the website content.
* CSS3: Controls the design, colours, layout, spacing, and responsiveness.
* JavaScript: Adds interactive functionality.
* Visual Studio Code: Used to write and manage the code.
* Live Server: Used to preview the website in a browser.
* Unsplash: Provides food images used in the website.

🌐 Website Features

1. Home Page

Introduces Quick Bite Fast Food with a welcoming headline, background image, and buttons that direct visitors to other sections.

2. About Section

Provides information about the restaurant, its commitment to quality food, and its focus on customer satisfaction.

3. Menu Section

Displays food items in vertical cards containing:

* Food images
* Food names
* Short descriptions
* Prices
* Order buttons

4. Services Section

Highlights the restaurant’s main services:

* Quality food
* Fast delivery
* Affordable prices

5. Contact Section

Provides a contact form where visitors can enter their name, email address, subject, and message.

The form opens the visitor’s default email application to prepare a message. It does not currently store messages in a database or send them directly from the website.

6. Responsive Design

The website adapts to different screen sizes using CSS media queries, allowing it to work on desktop computers, tablets, and mobile phones.

7. Navigation

The navigation menu allows visitors to move between the Home, About, Menu, Services, and Contact sections.

🚀 How to Run the Project

Requirements

* A computer with Visual Studio Code installed.
* A modern web browser, such as Google Chrome or Microsoft Edge.
* The Live Server extension in Visual Studio Code (recommended).

Installation Steps

1. Create a folder named QuickBite.
2. Open the folder in Visual Studio Code.
3. Create the following files:
    * index.html
    * style.css
    * script.js
    * README.md
4. Copy the appropriate code into each file.
5. Save all the files.
6. Install the Live Server extension if it is not already installed.
7. Right-click index.html.
8. Select Open with Live Server.
9. The website will open in your default browser.

Alternatively, you can open index.html directly in a browser, although Live Server is recommended during development.

🎨 Design and Layout

The website uses a clean restaurant-themed design with:

* Orange accent colours.
* Dark and white backgrounds.
* Food photography.
* Rounded menu cards.
* Consistent spacing and typography.
* Hover effects on selected buttons and cards.
* Responsive layouts for different devices.

The menu section uses three columns on larger screens, two columns on medium-sized screens, and one vertical card per row on smaller mobile screens.

🔧 Future Improvements

⚠️ Important Notes

* Food prices shown on the website are sample prices and should be updated to reflect the restaurant’s actual prices.
* The food images are loaded from external URLs and require an internet connection.
* The contact form requires a valid restaurant email address to be configured in script.js.
* The website does not currently have a backend or database.
* The project is a front-end website prototype.
